# Візуальні матеріали

Усі PNG у `assets/` підготовлені спеціально для Sheet: to do. Сторонні стокові
зображення, логотипи або матеріали з попередньої вебверсії не використовуються.

| Файл                                   | Призначення                        |
| -------------------------------------- | ---------------------------------- |
| `assets/branding/app-icon.png`         | Іконка застосунку та splash screen |
| `assets/branding/app-icon-ios.png`     | Іконка iOS 1024×1024               |
| `assets/backgrounds/twilight-nook.png` | Тема «Вечір»                       |
| `assets/backgrounds/winter-window.png` | Тема «Зима»                        |
| `assets/backgrounds/spring-window.png` | Тема «Весна»                       |
| `assets/backgrounds/autumn-attic.png`  | Тема «Осінь»                       |

Власник репозиторію дозволяє зберігати, змінювати, збирати та поширювати ці файли
як частину застосунку. Окреме перевидання зображень поза Sheet: to do не
ліцензовано.

Власний фон користувача не є частиною репозиторію. Застосунок вибирає його через
системний photo picker, стискає у JPEG і зберігає у приватній директорії на
пристрої. Такий файл не додається до Git, APK або експорту окремого списку.

Піктограми списків і кнопок — системні emoji платформи, а не окремі графічні файли.
