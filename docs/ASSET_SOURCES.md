# Походження візуальних assets

У застосунку немає зображень із папки `pictures` оригінальної вебверсії, Pinterest,
Google Images, CDN або сторонніх брендів. Усі перелічені нижче PNG створені спеціально
для цього мобільного репозиторію 21 липня 2026 року за допомогою вбудованого OpenAI
image generation tool.

Ліцензійний статус усіх п’яти файлів: first-party project asset. Власник репозиторію
дозволяє зберігати, змінювати, збирати та поширювати їх як частину застосунку
“Sheet: to do”. Окреме повторне видання assets поза цим застосунком не ліцензовано.
