# Встановлення Sheet: to do на Android

## Який файл потрібен

Для прямого встановлення потрібен `.apk`, а не `.aab`. Preview APK створюється так:

```powershell
npx eas-cli@latest build --platform android --profile preview
```

Локальна назва поточного релізу: `dist/sheet-to-do-0.4.0.apk`. APK не додається в Git.

```powershell
Get-FileHash dist\sheet-to-do-0.4.0.apk -Algorithm SHA256
```

Передавай checksum окремо від APK, якщо потрібно перевірити цілісність файла.

## Передача і встановлення

1. Передай APK через Telegram, WhatsApp, Viber, Signal, Drive, USB або Quick Share.
2. Відкрий APK на телефоні.
3. Якщо Android заблокує встановлення, відкрий запропоновані налаштування та увімкни
   **Дозволити з цього джерела** лише для програми, з якої відкрито APK.
4. Повернися до файла, перевір назву **Sheet: to do** і натисни **Встановити**.
5. Після успішного встановлення дозвіл для невідомих застосунків можна вимкнути.

Назви пунктів трохи відрізняються у Samsung One UI, Xiaomi HyperOS, Huawei EMUI та
інших оболонках.

## Встановлення через USB/ADB

```powershell
adb devices
adb install dist\sheet-to-do-0.4.0.apk
```

Оновлення поверх наявної версії:

```powershell
adb install -r dist\sheet-to-do-0.4.0.apk
```

## Оновлення без втрати даних

APK має використовувати package `com.lilydotsenko.sheettodo`, той самий EAS signing
key та більший `android.versionCode`. Встановлюй його поверх старої версії. Не роби
uninstall: він видаляє AsyncStorage, фотографії та власний фон.

Перед ризиковим оновленням відкрий sharing потрібного списку, вибери **Список із
фотографіями** і збережи файл `.sheettodo`. Сумісний JSON без фото також можна імпортувати.

## Дозволи для будильника

При першому створенні будильника:

1. дозволь сповіщення;
2. на Android 12+ дозволь Sheet: to do системний доступ **Будильники й нагадування**;
3. якщо виробник телефона агресивно обмежує фон, дозволь фоновий запуск і виключи
   застосунок з оптимізації батареї.

У визначений час застосунок запускає тривалий звук, повноекранний екран і постійне
сповіщення. Зупинити його можна кнопкою **Вимкнути будильник** на екрані або у
сповіщенні. Після надання системного доступу повернися в застосунок і задай час ще раз.

## Передавання списків через месенджери

Для читання людиною вибери **Як звичайний текст** — месенджер отримає назву, прогрес і
завдання без фото.

Для повного перенесення вибери **Список із фотографіями**. Застосунок створить один
файл `назва-списку.sheettodo`, який можна надіслати як документ через Telegram,
WhatsApp, Viber, Signal та інші програми, що підтримують файлові вкладення.

На телефоні одержувача:

1. встанови Sheet: to do 0.4.0 або новішу версію;
2. натисни отриманий `.sheettodo` і вибери **Sheet: to do**;
3. перевір назву, кількість завдань і фотографій;
4. натисни підтвердження імпорту.

Якщо месенджер відкриває вкладення лише у своєму переглядачі або не показує Sheet: to
do, збережи файл у **Завантаження**, відкрий застосунок, натисни **Імпорт** і вибери
файл. Це передбачений fallback; сервер або інтернет для імпорту не потрібні.

## Сумісність резервних копій

- `.sheettodo` переносить JPEG-фотографії й потребує Sheet: to do 0.4.0+;
- старі `.sheet-to-do.zip` пакети продовжують імпортуватися;
- JSON і deep links сумісні зі старими версіями, але не містять фото;
- читабельний текст не призначений для автоматичного імпорту;
- власний фон є налаштуванням конкретного телефона і не входить у пакет списку.

## Типові помилки

- **App not installed** — інший signing key, замалий versionCode, пошкоджений файл або
  непідтримувана версія Android.
- **Problem parsing the package** — завантаження APK обірвалося; звір SHA-256 і
  завантаж файл знову.
- **Sheet: to do не з'являється для `.sheettodo`** — збережи вкладення локально й
  скористайся кнопкою **Імпорт**. Різні месенджери по-різному передають MIME-тип.
- **Будильник не запускається** — перевір сповіщення, **Будильники й нагадування** та
  налаштування фонової роботи/батареї.
- **Списки зникли після reinstall** — uninstall очищає приватні дані; імпортуй раніше
  збережений `.sheettodo` або JSON. Лише `.sheettodo`/старий ZIP переносить фото.
