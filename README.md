# Sheet: to do

Мобільний офлайн-планер для Android. Застосунок зберігає списки, завдання,
розклади та фотографії локально на пристрої й не потребує облікового запису або
власного сервера.

## Що вміє застосунок

- створювати окремі списки та впорядковувати їх перетягуванням;
- додавати й виконувати завдання, стежити за прогресом списку;
- планувати списки та окремі завдання в календарі;
- створювати точні Android-будильники з повноекранним сповіщенням;
- прикріплювати локальні фотографії до завдань;
- перемикати мову інтерфейсу між українською та англійською;
- вибирати одну з чотирьох тем або власне фонове зображення;
- надсилати список як звичайний текст;
- експортувати та імпортувати список разом із фотографіями у файлі
  `.sheettodo`.

## Технології

- Expo SDK 57 і React Native 0.86;
- Expo Router;
- TypeScript у strict-режимі;
- AsyncStorage для метаданих;
- Expo FileSystem для фотографій і фонових зображень;
- Notifee для точних Android-будильників;
- Jest, ESLint і Prettier.

## Вимоги

- Node.js 22 LTS або новіший;
- npm;
- Android Studio та Android SDK для локальної Android-збірки;
- EAS CLI лише для хмарної збірки.

Notifee є нативним модулем, тому повний застосунок не працює у звичайному Expo
Go. Для перевірки будильників потрібен development build або зібраний APK.

## Локальний запуск

Встанови залежності:

```powershell
npm install
```

Запусти development server:

```powershell
npm run dev
```

Для локальної Android-збірки:

```powershell
npm run android
```

## Перевірки

Перед змінами або збіркою виконай:

```powershell
npm run format:check
npm run lint
npm run typecheck
npm test
npm run doctor
```

Доступні також `npm run test:watch` для роботи з тестами та `npm run format` для
автоматичного форматування.

## Збірка APK

Development build:

```powershell
npx eas-cli@latest build --platform android --profile development
```

Preview APK для прямого встановлення:

```powershell
npx eas-cli@latest build --platform android --profile preview
```

Production-профіль створює AAB. Команди EAS лише запускають збірку й нічого не
публікують у Google Play автоматично.

Інструкція зі встановлення та оновлення APK: [docs/ANDROID_INSTALL.md](docs/ANDROID_INSTALL.md).

## Структура проєкту

```text
src/
  app/          маршрути та екрани Expo Router
  components/   картки, модальні вікна й елементи інтерфейсу
  domain/       моделі, операції над даними та міграції
  i18n/         переклади й локалізація календаря
  services/     сховище, файли, імпорт/експорт і сповіщення
  state/        стан застосунку та React Context
  theme/        теми й піктограми
assets/         іконка та вбудовані фони
docs/           додаткові інструкції
```

## Дані та резервні копії

Метадані зберігаються в AsyncStorage під ключем `sheet-to-do:data`. Фотографії та
власний фон лежать окремими JPEG у приватній директорії застосунку. Пошкоджений
payload переноситься до `sheet-to-do:data:corrupt`, після чого застосунок
відновлюється з порожнім набором даних.

Файл `.sheettodo` містить один список і його доступні фотографії. Імпорт перевіряє
формат, версію, розміри, CRC32 та безпечність шляхів усередині архіву. Власний фон
не входить до резервної копії списку.

Детальний опис архітектури: [docs/TECHNICAL_DOCUMENTATION.md](docs/TECHNICAL_DOCUMENTATION.md).
Локальна модель даних, міграції та формат `.sheettodo`:
[docs/DATA_DOCUMENTATION.md](docs/DATA_DOCUMENTATION.md).

Видалення застосунку очищає його приватні дані. Перед перевстановленням експортуй
важливі списки через меню поширення.

## Обмеження

- хмарної синхронізації немає;
- `.sheettodo` переносить один список за раз;
- надійність будильників залежить від системних дозволів і налаштувань економії
  батареї конкретного виробника;
- пряме відкриття `.sheettodo` залежить від того, який MIME-тип передає месенджер;
  кнопка **Імпорт** у застосунку є надійним резервним способом.

Походження та умови використання візуальних файлів описані у
[docs/ASSET_SOURCES.md](docs/ASSET_SOURCES.md).
